API Usage Documentation

This document separates the APIs based on whether they are routed through the central API service (Auth.js and Axios Interceptor) or called directly from individual components/utilities (separately).

1. APIs Coming From Central Service (Auth.js)

These APIs are managed centrally using the Axios instance (api) which likely includes authorization headers and base URL configurations.

  • Authentication & Doctor Details
    • postLogin - POST /PhysioDoctorlogin
    • getDoctorDetails - GET /getDoctorById/{doctorId} (fallback to /api/doctors/getDoctorById/{doctorId})
    • updateLogin - PUT /update-PhysioDoctorpassword/{userName}
    • updateAvailability - PUT /update-PhysioDoctorAvailability/{doctorId}
  • Appointments
    • getTodayAppointments - GET /getTodaysAppointmentsByUsingClinicIdAndDoctorId/{hospitalId}/{doctorId}
    • getTodayFutureAppointments - GET /getFutureDoctorappointmentsByDoctorId/{doctorId}
    • getAppointments - GET /getDoctorAppointmentsonStatus/{hospitalId}/{branchId}/{doctorId}/{status}
    • getAppointmentsCount - GET /appointments/completed/{hospitalId}/{doctorId}
    • updateAppointmentBasedOnBookingId - PUT /clinic-admin/updateAppointmentBasedOnBookingId
  • Prescriptions & Medicines
    • SavePrescription - POST /physiotherapy-record/createPrescription
    • SearchPrescription - GET /physiotherapy-record/searchMedicines
    • SavePatientPrescription - POST /physiotherapy-record/create (Uses direct axios)
    • getDoctorSaveDetails - GET /physiotherapy-record/getTemplatesByClinicIdAndTitle/{hospitalId}/{disease}
    • medicineTemplate - GET /physiotherapy-record/getPrescriptionsByClinicId/{clinicId}
    • getMedicineTypes - GET /getMedicineTypes/{clinicId}
    • addMedicineType - POST /search-or-add
  • Lab Tests & Diseases & Treatments
    • getAllLabTests - GET /clinic-admin/labtest/getAllLabTests
    • getLabTests - GET /clinic-admin/labtests/{hospitalId}
    • addLabTest - POST /clinic-admin/addOrGetTest
    • getAllDiseases - GET /clinic-admin/diseases/{hospitalId}
    • addDisease - POST /clinic-admin/addDiseases
    • getAllTreatments - GET /clinic-admin/treatment/getAllTreatments
    • getAllTreatmentsByHospital - GET /clinic-admin/treatments/{hospitalId}
    • addTreatmentByHospital - POST /clinic-admin/addOrGetTreatment
    • getTreatmentStatusByVisitId - GET /visitHistoryBypatientIdAndBookingId/{patientId}/{bookingId} (Uses direct fetch in Auth.js)
  • Clinic, Ratings & Vitals
    • getClinicDetails - GET /admin/getClinicById/{hospitalId}
    • averageRatings - GET /clinic-admin/getAverageRatingsByDoctorId/{doctorId}
    • getPatientVitals - GET /clinic-admin/getVitals/{bookingId}/{patientId}
  • Reports
    • ReportsData - GET /clinic-admin/getallreports
    • Get_ReportsByBookingIdData - GET /clinic-admin/getReportByBookingId/{bookingId}
  • Ads & Media Images
    • getAdImages - GET /admin/categoryAdvertisement/getAll
    • getAdImagesView - GET /admin/doctorWebAds/getAll
    • saveImagesToServer - POST /admin/images/save
    • loadImagesFromServer - GET /admin/images/getAll
    • clearImagesOnServer - DELETE /admin/images/clearAll
  • Therapy & Progress
    • getInProgressDetails - GET /getIn-progressByUsingPatientIdAndBookingId/{patientId}/{bookingId}
    • getExerciseSessionsByExerciseId - GET /api/customer/therapy-records/getByClinicBranchExercise/...
    • getExerciseSessionsWithRecords - GET /payment/getExerciseSessionsWithRecords/...
    • getCompletedTherapyRecord - GET /getCompletedTherapyRecord/...

2. APIs Using Separate/Direct Calls (Not using Central Service)

These APIs are invoked directly from within components or utility files, using native fetch or a separate axios call without the central interceptor.

  • Attendance Tracker (views/attendance/AttendanceTracker.js)
    • POST /clinic-admin/saveUserAttendence (Direct Axios)
    • PUT /clinic-admin/updateUserAttendence (Direct Axios)
    • GET External/Dynamic API URLs for IP address fetching (Direct Axios)
  • Completed Appointment View (components/ComplatedAppointmnetView.js)
    • GET /api/patients/{id} (Direct Fetch)
  • S3 Upload Services (utils/S3UploadServices.js)
    • PUT/GET Direct AWS S3 bucket endpoints for media uploads (Direct Fetch)
  • File Uploader (Prescription/FileUploader.js)
    • GET/POST Dynamically passed URLs for fetching/uploading files (Direct Fetch)
